💸 BudgetWise

Smart budgeting app to track income, expenses, and savings — powered by Firebase.

📌 About

BudgetWise is a simple and intuitive budgeting application designed to help users stay in control of their finances. It allows you to track income, expenses, and savings while keeping everything synced securely in the cloud via Firebase.
The goal is to make financial awareness effortless, clear, and accessible.

✨ Features

Track income, expenses, and savings
Real-time data sync with Firebase
Clean and user-friendly interface
Categorized transactions
Overview of monthly balance

🛠️ Tech Stack

React
Firebase (Auth, Firestore, Hosting)
